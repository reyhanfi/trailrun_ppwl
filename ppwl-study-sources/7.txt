Bab 1. Pendahuluan
1.1 Latar Belakang
Pengelolaan data merupakan bagian penting dalam pengembangan aplikasi web. Pada prak-
tikum ini, tur pengelolaan data diterapkan pada dua proyek Laravel, yaitu katalog buku dan
daftar event lari. Data awal disiapkan menggunakan seeder, kemudian ditampilkan dan diolah
melalui controller serta view Blade.
1.2 Tujuan Praktikum
1. Membuat data awal menggunakan seeder dengan 20 record pada masing-masing proyek.
2. Menampilkan lima data terbaru pada halaman web.
3. Menerapkan penyaringan data berdasarkan penulis atau tipe event.
4. Menampilkan statistik yang sesuai dengan data proyek.
5. Menerapkan pencarian serta memberikan informasi ketika hasil tidak ditemukan.

Bab 2. Dasar Teori
2.1 Seeder dan Data Awal
Seeder adalah kelas Laravel yang digunakan untuk mengisi basis data dengan data awal. Me-
thodrun()pada seeder memuat operasi penyimpanan data, sedangkanDatabaseSeederdapat
memanggil seeder lain untuk mengatur rangkaian pengisian data. Pada proyek ini, data buku
dan event didenisikan pada seeder masing-masing.[1]
2.2 Model, Controller, dan Routing
Model mewakili data yang disimpan di basis data. Controller menerima permintaan, menja-
lankan query melalui model, dan mengirimkan data yang diperlukan ke view. Route meng-
hubungkan alamat URL dengan method controller sehingga halaman dapat dibuka melalui
browser.[2]
2.3 View Blade
Blade merupakan template engine Laravel yang menyediakan sintaks untuk menampilkan
data, melakukan perulangan, dan memilih tampilan berdasarkan kondisi. Dalam proyek ini,
view menampilkan tabel, formulir GET, pesan hasil kosong, serta statistik.[3]
2.4 Filter, Pencarian, dan Statistik
Filter memilih record yang sesuai dengan nilai tertentu, misalnya penulis atau tipe event.
Pencarian membandingkan kata kunci dengan judul buku atau nama event. Statistik dapat
dihitung dari data menggunakan operasi hitung seperti jumlah, total, nilai maksimum, dan
nilai minimum. Laravel menyediakan query dan koleksi untuk membantu proses pemilihan serta
pengolahan data.[4]

4.1 Kesimpulan
1. Seeder pada proyek Buku dan Trail Run digunakan untuk menyiapkan masing-masing 20
data awal.
2. Controller dan model mengolah data untuk menampilkan lima data terbaru, lter, penca-
rian, serta statistik.
3. View Blade menampilkan data dalam tabel dan mempertahankan kata kunci pencarian
setelah form dikirim.
4. Kedua proyek memberikan pesan saat pencarian tidak menemukan data. Statistik Bu-
ku mengikuti hasil yang sedang ditampilkan, sedangkan statistik Trail Run merangkum
seluruh data event.
