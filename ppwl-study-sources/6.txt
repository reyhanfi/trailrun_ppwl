Bab 2. Dasar Teori
2.1 Routing di Laravel
Routing adalah proses pengaturan URL agar setiap permintaan HTTP dapat dipetakan ke
fungsi atau controller tertentu. Dalam Laravel, kongurasi route biasanya diletakkan pada le
routes/web.php, yang berperan sebagai titik masuk permintaan pengguna ke aplikasi. Dengan
routing, aplikasi dapat membedakan halaman utama, halaman tentang, maupun halaman yang
menangani data tertentu, sehingga struktur navigasi dapat diatur secara terorganisir dan mudah
dikembangkan [1].
2.2 Controller dan View
Controller merupakan komponen yang berisi logika aplikasi untuk menangani proses terten-
tu sebelum data dikirim ke tampilan. Di Laravel, controller biasanya disimpan pada folder
app/Http/Controllersdan digunakan untuk memanggil view yang sesuai dengan kebutuhan
aplikasi. View sendiri berisi markup HTML dan berfungsi menampilkan hasil data ke penggu-
na, sementara Blade digunakan sebagai template engine yang mempercepat proses pembuatan
halaman tanpa menuliskan logika berulang [2].
2.3 Migration dan Manajemen Database
Migration adalah tur Laravel untuk mengelola struktur database melalui kode, bukan me-
lalui perubahan manual di database. Dengan migration, pembuatan tabel, perubahan kolom,
maupun penghapusan struktur dapat dilakukan secara terdokumentasi dan reproducible. Hal
ini sangat berguna dalam pengembangan proyek karena setiap perubahan struktur data dapat
diikuti dan dipelihara dengan rapi, sehingga konsistensi database tetap terjaga selama proses
pengembangan [3].

Bab 4. Kesimpulan
4.1 Kesimpulan
1. Routing pada Laravel memungkinkan setiap URL dipetakan ke fungsi atau controller ter-
tentu sehingga aplikasi lebih teratur dan mudah dikelola.
2. Controller berperan sebagai penghubung logika aplikasi dan tampilan, sehingga code men-
jadi lebih terstruktur serta mudah untuk dikembangkan.
3. Migration membantu menjaga struktur database tetap konsisten dan terdokumentasi, se-
hingga perubahan data dapat dijalankan dengan aman dan rapi.
