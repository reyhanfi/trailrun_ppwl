Bab 1. Hasil dan Pembahasan
1.1 Pengayaan
1.1.1 Konsep Dasar CRUD
Pertanyaan 1:Jelaskan apa yang dimaksud dengan CRUD dan sebutkan kepanjangannya!
Jawaban:CRUD merupakan akronim dari Create, Read, Update, dan Delete, yaitu empat
operasi fundamental dalam manajemen data. Create menambah data baru via SQL INSERT,
Read menampilkan data menggunakan SELECT, Update mengubah data dengan UPDATE, dan
Delete menghapus data melalui DELETE.[1]
Pertanyaan 2:Mengapa penting bagi seorang pengembang web memahami CRUD meng-
gunakan PHP native sebelum menggunakan framework seperti Laravel?
Jawaban:Pemahaman PHP native memberikan fondasi yang kuat tentang alur data dari
form ke database. Tanpa pemahaman dasar ini, developer akan kesulitan saat debugging di
framework, tidak dapat mengoptimalkan query, dan tidak memahami apa yang terjadi di balik
abstraksi framework.[2]
1.1.2 Koneksi Database
Pertanyaan 3:Sebutkan dan jelaskan keempat parameter pada fungsi mysqli_connect()!
Jawaban:Parameter mysqli_connect() adalah: (1)localhost- alamat server MySQL,
(2)root- username (default XAMPP), (3) string kosong - password (default XAMPP tanpa
password), (4)toko_buku- nama database.[3]
Pertanyaan 4:Apa fungsi kodeif (!$koneksi) { die(...); }pada koneksi.php?
Jawaban:Kode ini adalah error handling yang memeriksa apakah koneksi gagal (meng-
embalikan false). Jika gagal, program dihentikan dan menampilkan pesan error spesifik dari
MySQL, mencegah eksekusi kode selanjutnya yang menyebabkan error tambahan.[2]
Pertanyaan 5:Mengapafilekoneksi.phpdi-includepadahampirsemuafileCRUDlainnya?
Jawaban:Dengan include, variable $koneksi tersedia untuk menjalankan query. Ini meng-
hindari duplikasi kode dan memudahkan maintenance karena perubahan konfigurasi database
hanya perlu di satu file.[1]

1.1.3 Create (Menambah Data)
Pertanyaan 6:Jelaskan mengapa proses Create dipisah menjadi tambah.php dan pro-
ses_tambah.php!
Jawaban:Pemisahan ini menerapkan Separation of Concerns: tambah.php menampilkan
form (presentasi), proses_tambah.php memproses data dan simpan ke database (logika). Ini
membuat kode terstruktur, mudah di-debug, dan mengikuti pola GET (menampilkan) vs POST
(memproses).[1]
Pertanyaan 7:Tuliskan query SQL INSERT untuk menambah buku "Bumi Manusia",
penulis "Pramoedya Ananta Toer", harga 95000, tgl "1980-08-10"!
Jawaban:
1INSERT INTO buku ( judul , penulis , harga , t g l _ t e r b i t )
2VALUES ( ’ Bumi Manusia ’ , ’ P ram oe dy a Ananta Toer ’ , 95000 , ’
1980 -08 -10 ’) ;
Kolomidtidak perlu ditulis karena AUTO INCREMENT.
Pertanyaan 8:Apa fungsiheader("Location: index.php");?
Jawaban:Header ini melakukan redirect ke index.php setelah data berhasil disimpan. Tu-
juannya adalah memberikan feedback visual kepada user bahwa proses sukses, dan user langsung
melihat data baru di daftar.[2]
1.1.4 Read (Menampilkan Data)
Pertanyaan 9:Jelaskan fungsi mysqli_fetch_assoc() dan mengapa di dalam perulangan
while!
Jawaban:mysqli_fetch_assoc() mengambil satu baris sebagai array asosiatif (key = nama
kolom). Dalam while loop, setiap iterasi mengambil baris berikutnya sampai tidak ada data
(false). Loop otomatis berhenti tanpa perlu hitung jumlah baris.[2]
Pertanyaan 10:Tuliskan query SQL menampilkan data buku diurutkan harga termahal
ke termurah!
Jawaban:
1SELECT * FROM buku ORDER BY harga DESC ;
DESC = descending (besar ke kecil), ASC = ascending.
Pertanyaan 11:Cara menampilkan nilai kolom judul dari variabel $buku?
Jawaban:echo $buku[’judul’];Karena mysqli_fetch_assoc() mengembalikan array
asosiatif, akses menggunakan nama kolom sebagai key.

1.1.5 Update (Mengubah Data)
Pertanyaan 12:Mengapa edit.php perlu ambil data lama (SELECT WHERE id) sebelum
tampilkan form?
Jawaban:Data lama diperlukan untuk pre-fill form agar user dapat melihat nilai saat ini,
memudahkan editing. Juga validasi bahwa data dengan ID tersebut ada, dan menentukan target
yang tepat untuk UPDATE.[1]
Pertanyaan 13:Tuliskan query SQL UPDATE mengubah harga buku id=3 menjadi
120000!
Jawaban:
1UPDATE buku SET harga = 120000 WHERE id = 3;
WHERE clause sangat kritis, tanpanya seluruh tabel akan terupdate.
Pertanyaan 14:Jelaskan fungsi hidden input<input type="hidden" name="id">!
Jawaban:Hidden input menyimpan ID data yang sedang diedit. Field tidak terlihat di
layar tetapi tetap dikirim saat form submit, sehingga proses_edit.php tahu ID mana yang harus
di-update.[1]
1.1.6 Delete (Menghapus Data)
Pertanyaan 15:Apa terjadi tanpa WHERE padaDELETE FROM buku? Jelaskan risiko!
Jawaban:Query akan menghapus SEMUA baris tabel, bukan hanya satu baris. Risikonya
adalah kehilangan seluruh data permanen. Menurut OWASP, ini termasuk kerentanan kritis
yang dapat menyebabkan data loss total dan business disruption.[4]
Pertanyaan 16:Tuliskan query SQL menghapus data buku id=7!
Jawaban:
1DELETE FROM buku WHERE id = 7;
WHERE clause adalah mandatory untuk keamanan dan data integrity.
