Bab 2. Dasar Teori
2.1 Routing di Laravel
Routing adalah mekanisme untuk menentukan bagaimana aplikasi merespon permintaan HT-
TP pada URL tertentu. Pada Laravel, rute didenisikan di le dalam folder `routes/`, misalnya
`web.php` untuk routing web biasa. Rute dapat mengembalikan view langsung, memanggil con-
troller, atau mengembalikan response lain. Penentuan rute yang jelas memudahkan navigasi
aplikasi serta pemisahan concerns antara URL, logika, dan tampilan [1].
2.2 View dan Blade
View adalah le yang berisi markup HTML yang digunakan untuk menampilkan data ke
pengguna. Dalam Laravel, view disimpan pada direktoriresources/viewsdan biasanya di-
tulis menggunakan Blade  template engine milik Laravel. Blade menyediakan direktif seperti
@extends,@section,@yield, dan@includeyang mempermudah template inheritance dan peng-
gunaan partials. Blade dikompilasi menjadi PHP biasa sehingga memiliki performa yang baik
dan tidak menambah overhead signikan saat runtime [1].
2.3 Manfaat Template Engine dan Optimasi
Penggunaan template engine seperti Blade memfasilitasi pemisahan logika dan tampilan,
mengurangi duplikasi kode, serta memungkinkan prekompilasi tampilan untuk optimasi perfor-
ma (mis. `php artisan view:cache`). Kajian akademik terkait pemilihan dan evaluasi mesin
template menunjukkan bahwa pemilihan engine mempengaruhi kecepatan kompilasi, kemudah-
an pemeliharaan, dan dukungan ekosistem, sehingga pemahaman karakteristik engine penting
saat memilih teknologi untuk proyek skala menengah hingga besar [2][3].
